

FreeDungeon
===========


Freedungeon is a game with the aim to make a free software clone of the game
Dungeon Master, containing free assets making it easily distributable in
Free Software distributions.



## Keyboard

```
Movement: QWE
          ASD

Ctrl+Alt+M - Map
Ctrl+Alt+N - Show debug information
Ctrl+Alt+X - Quit program
```

in inventory screen (for debug purposes):

```
V - torch
B - skeleton key
```

## Internal

### GameState

Basically two states:

Main menu

or

Explore - actually ingame




### GameModes

Explore, inventory, paused, options dialog (maybe the dialogs for loading and
saving too?)
